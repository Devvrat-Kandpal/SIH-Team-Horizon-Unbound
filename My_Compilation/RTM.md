## 3. Verification Methodologies

1. **Unit Testing (`tests/test_unit.py`)**: Validates physical mathematical relationships without network or UI dependencies.
2. **API Contract Testing (`tests/test_api.py`)**: Tests 100% of REST routes, HTTP response status codes, payload structures, and error handling.
3. **Real-Time Protocol Testing (`tests/test_websocket.py`)**: Tests WebSocket handshake security, frame transmission schemas, and bidirectional control execution.
4. **Statistical Verification (`tests/test_criticality.py`, `tests/test_ablation.py`)**: Verifies multi-seed reproducibility, zero false alarms on nominal Gaussian noise, and monotonic criticality ranking.
5. **Quantitative Benchmark (`evaluate_model.py`)**: Runs high-throughput evaluation against 7,500 unseen test vectors and outputs `reports/evaluation_report.json` and `reports/ablation_study.md`.
